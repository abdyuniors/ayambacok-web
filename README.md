# 🐔 AyamBacok - Website Profil & Pemesanan

Repositori ini berisi kode sumber untuk website _landing page_ **AyamBacok**, sebuah platform digital sederhana untuk usaha rumahan yang menjual ayam pedaging (broiler) hidup.

Website ini dirancang untuk memuat informasi secepat kilat dan mengarahkan calon pembeli untuk langsung melakukan pemesanan melalui WhatsApp Business.

## ✨ Fitur Utama

- **Performa Ekstrem:** Dibangun menggunakan Astro (Zero-JS) sehingga _loading_ website sangat cepat.
- **Desain Responsif:** Tampilan rapi di HP, Tablet, maupun Laptop berkat Tailwind CSS.
- **Integrasi WhatsApp:** Tombol pemesanan yang langsung mengarah ke chat WhatsApp dengan teks yang sudah terisi otomatis (Pre-filled message).
- **Integrasi Google Maps:** Tombol navigasi untuk mengarahkan pembeli langsung ke lokasi kandang/rumah.

## 🛠️ Teknologi yang Digunakan

- [Astro](https://astro.build/) - Web Framework
- [Tailwind CSS](https://tailwindcss.com/) - CSS Framework
- [Vercel](https://vercel.com/) - Platform Hosting (Deployment)
